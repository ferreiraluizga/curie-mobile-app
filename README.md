## 📚 O que é o CURIE?

<p>O CURIE é uma aplicação multiplataforma que combina diversos aspectos importantes para o aluno. Contando com uma ferramenta de gestão de tarefas, análise do desempenho acadêmico, apoio emocional, análise do perfil do estudante para uma vocação adequada. Além disso, ao possuir uma inteligência artificial para auxiliar o planejamento de pesquisas, contribui para o aumento do rendimento acadêmico e melhora a comunicação entre aluno e professor. O problema ocorre porque, recorrentemente, é cobrado que ele saiba qual carreira seguir; entretanto, não é indicado como ele deve descobrir uma profissão de acordo com as suas características, muitas vezes únicas, de modo que podem ser desperdiçadas, caso a escolha profissional não seja adequada. O sistema atuará como instrumento de orientação vocacional. O CURIE ajudará o discente a descobrir as melhores opções para a sua carreira, equivalentes às suas características pessoais.
</p>

> Para maiores detalhes sobre o projeto, baixe a [documentação](https://github.com/user-attachments/files/23809974/ptcc-curie.pdf)

## 🌐 Aplicação Web

![languages](https://skillicons.dev/icons?i=php,html,css,js,bootstrap,mysql,laravel)

A aplicação web tem como objetivo a comunicação, o gerenciamento de assinaturas e páginas de controle para o admin dividindo-se em duas partes principais:

- [x] **Site Público para Clientes:** Fórum, assinaturas e informações sobre o mobile;
- [x] **Painel Administrativo:** Área exclusiva para administradores, com acesso direto ao banco de dados e visualização completa das tabelas. Com todas as funcionalidades;

> Para uso da aplicação e informações de funcionamento, navegue até a branch [web_app](https://github.com/ferreiraluizga/curie-web-app)


## 📱 Aplicação Mobile

![languages](https://skillicons.dev/icons?i=kotlin,sqlite,sping)

O aplicativo mobile do CURIE foi desenvolvido para fornecer ao estudante uma experiência personalizada, unindo organização acadêmica, testes de perfil e suporte via IA.

- [x] **Tela Inicial:**  Exibe análise geral do perfil vocacional, plano de carreira, dados essenciais e tarefas/metas próximas do vencimento.

- [x] **Gerenciador de Tarefas:**  Criar, visualizar, atualizar e excluir tarefas e metas, organizadas por prazo.

- [x] **Análise de Perfil:** Três testes disponíveis — comportamental, temperamental e vocacional, com resultados armazenados no sistema.

- [x] **CURIE Assistant:** Chat com inteligência artificial para auxiliar estudos, pesquisas e dúvidas acadêmicas.

> Para uso da aplicação e informações de funcionamento, navegue até a branch [mobile_app](https://github.com/ferreiraluizga/curie-mobile-app)
